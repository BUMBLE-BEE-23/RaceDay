# RaceDay Database Validation Notes

The RaceDay database is designed for SQL Server.

The database contains six core entities:
1. Users
2. EventTypes
3. Events
4. Categories
5. Enrollments
6. Results

The SQL script creates primary keys, foreign keys, required fields, unique constraints, default values and validation checks.

Seed data includes:
- 2 organizers
- 2 participants
- 3 events
- Event types
- Categories
- Sample enrolments
- Sample results
