# RaceDay Ownership Rules

Organizers can manage only resources belonging to their own events.

For event management:
- The logged-in organizer can create events.
- An organizer can update or delete only their own events.

For categories:
- An organizer can create, update and delete categories only for events they own.

For enrolments:
- Organizers can view enrolments belonging to their own events.
- Participants can view only their own enrolments.

For results:
- Organizers can record and update results only for participants enrolled in their own events.
- Participants can view only their own results.

These ownership rules will be enforced in the API service/controller logic.
